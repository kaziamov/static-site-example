# Order Notifications Shopify App Pricing proof - production verification

## Summary

The reported issue was caused by an incorrect link to the app's pricing page. The link pointed to the wrong address, so opening it redirected to a page that did not exist instead of the app's pricing screen.

## Changes implemented

* The link to the pricing page was corrected so it points to the right destination.
* Pricing plans and current usage are shown directly inside the embedded app, so reviewers and merchants no longer need to leave the app to see them.
* The app no longer offers a link that could redirect to a non-existent page.

## Current status

The issue is resolved. The embedded Pricing page opens and reloads correctly in both our production and staging environments, with no errors and no broken redirects. This has been verified through direct testing.
